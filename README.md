# 🛡️ ShipGuard AI — Backend

### Know what to fix before you ship.

ShipGuard AI is a developer-focused security scanning platform designed to help developers, indie hackers, and small SaaS teams identify potential security issues before shipping their applications.

The backend is built with **ASP.NET Core Web API, C#, MongoDB, and Trivy**. It provides the foundation for authentication, repository management, security scanning, and scan-result handling.

### Mission

Make application security easier to understand and more accessible, helping developers identify potential risks earlier in the development lifecycle.

### Technology Stack

- **Backend:** ASP.NET Core Web API
- **Language:** C#
- **Database:** MongoDB
- **Security Scanner:** Trivy
- **API Documentation:** Swagger / OpenAPI

### Project Status

ShipGuard AI is currently under development as an early-stage prototype. The project is being built to validate real-world needs and gather feedback from developers.
